# riyadh-real-estate-ai
# 🏠 Riyadh Real Estate Price Prediction & Investment Advisor

An end-to-end Machine Learning web application built to analyze and predict residential property prices in Riyadh across various districts. The system leverages real-time market indicators and applies advanced regression models to estimate current property values and forecast annual market appreciation rates.

## 🚀 Key Features
•⁠  ⁠*Advanced Machine Learning Pipeline:* Built using Python, Scikit-learn (⁠ RandomForestRegressor ⁠), and Pandas with One-Hot Encoding for dynamic categorical feature handling (Regions, Districts, and Property Types: Villas & Apartments).
•⁠  ⁠*Interactive UI Dashboard:* Developed using *Streamlit* to provide a seamless user experience for exploring features, adjusting property dimensions, and visualizing real-time predictions.
•⁠  ⁠*Smart Investment Advisor:* Integrated localized analytical logic that computes expected annual growth rates, property age depreciation, and provides automated investment ratings (High Growth Potential, Stable & Secure).
•⁠  ⁠*Production-Ready Structure:* Automated model training and caching workflows using Joblib for optimized web execution.

## 🛠️ Tech Stack
•⁠  ⁠*Language:* Python
•⁠  ⁠*Libraries:* Pandas, NumPy, Scikit-learn, Joblib
•⁠  ⁠*Frontend / Dashboard:* Streamlit

## ⚙️ How to Run Locally

1.⁠ ⁠Clone the repository:
git clone https://github.com/renadalotaiibi0/riyadh-real-estate-ai.git

3.⁠ ⁠Run the Streamlit application:
